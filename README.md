# 구름 시장: 하늘빛 등불 상점

중1 대푯값 단원에서 출발한 8단계 거래·재고 전략 게임입니다. 손님이 원하는 목적에 맞춰 자료를 읽고 등불 묶음을 만듭니다. 수량만큼 제작비를 먼저 쓰며, 배송 보상을 다음 주문에 재투자합니다. 두 칸 수레, 합배송, 도착 시각의 돌풍, 유료 포장과 우회길이 서로 다른 전략을 만듭니다. 되돌리기와 재도전, 별 보상을 제공합니다.

## 실행과 배포
`npm test`, `npm run build`, `npm start`로 독립 실행합니다. Vercel에서 이 저장소를 Import하면 `vercel.json`에 따라 정적 빌드합니다. 실제 배포 URL은 아직 확인되지 않았습니다. 빌드에 원본 교과서나 추출문을 포함하지 않습니다.

## 성취기준 확인
교육부 고시 제2022-33호 [별책8], PDF46쪽(인쇄40쪽)의 9수04-01에 맞춰 의미, 중앙값, 최빈값, 목적별 선택·계산을 확인합니다. 해설47쪽·적용 고려48쪽도 대조했습니다. 3종 문항 세트의 새로운 수와 상황을 사용하고, 첫 응답·오답·재시도·도움 기록을 보존합니다. 도움과 같은 문항 재시도를 독립 수행으로 세지 않습니다. 학생 설명과 교사 검토·JSON 내보내기·인쇄를 지원하며 공식 이수 판정은 아닙니다. 교사 신원 인증 기능은 없습니다.

기록은 익명으로 이 브라우저에만 저장됩니다. 다인 사용 시 학습 확인 화면에서 기록을 내보내고 새 학습자를 시작하세요. 게임의 대푯값 선택과 거래 로그는 학습 확인의 독립 증거와 구분합니다. 게임을 새로 열면 마지막 장터를 처음부터 다시 시작하며 완료 별과 거래 기록은 유지합니다.

## 그래픽과 서체
내장 image_gen으로 시장 배경, 레서판다 상인, 등불·수레·돌풍·보상 아틀라스를 생성했습니다. 파일과 원문 프롬프트는 `assets/`에 있습니다. 수식·자료·숫자는 코드로 표시합니다. Jua / Do Hyeon / Gowun Dodum 서체와 원래 라이선스는 `theme/`에 포함했습니다.

## 검증과 한계
모든 임무의 해와 승리 경로, 단순 전략이 실패하는 반례, 포장비·시간 선택의 차이를 자동 테스트합니다. 실제 브라우저 및 390px 화면·평가 기록 검증은 `evidence/browser-review.json`을 확인하세요. 실제 학생의 재미나 학습 효과를 실험한 것은 아닙니다. 실제 시장에서는 표본이 미래 수요를 보장하지 않으며, 열린 상황의 대푯값 선택은 목적과 근거를 함께 검토해야 합니다.
